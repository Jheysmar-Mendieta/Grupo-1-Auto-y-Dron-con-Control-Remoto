# Manual de Usuario - Control de Auto y Dron (Grupo 1)

## 1. Introduccion
Guia simple para usar la aplicacion movil de Android (`ControlAutoDron_Grupo1.apk`) con el auto robot y el dron.

## 2. Como conectar y manejar el Auto Robot
1. Encender el interruptor de las baterias del auto.
2. En el celular, apagar los datos moviles y conectarse a la red Wi-Fi:
   * **Nombre:** `AutoRobot_Grupo1`
   * **Clave:** `12345678`
3. Abrir la app **Control Auto y Dron Grupo 1** y entrar en **Auto**.
4. Usar las flechas en pantalla para avanzar, retroceder y girar (o activar el Modo Volante con el giroscopio del celular).
5. Usar los botones de la camara (`45°`, arriba y abajo) para ajustar el angulo del servo.
6. Si el sensor ultrasonico detecta una pared a menos de 12 cm, el auto frena hacia adelante para evitar chocar.

## 3. Como usar el modo Dron
1. Conectarse al Wi-Fi del dron Tello y abrir la pantalla **Dron** en la app.
2. Usar los botones de despegue, aterrizaje y los mandos en pantalla o el simulador integrado.
