# Manual de Usuario - Control de Auto y Dron (Grupo 1)

## 1. Introducción
Este manual describe los pasos para operar el vehículo terrestre (auto) y la aeronave (dron) mediante la aplicación móvil con sensor de movimiento giroscópico.

## 2. Requisitos Previos
* Smartphone con navegador moderno (Chrome, Safari, Edge) con soporte para giroscopio y acelerómetro.
* Vehículo encendido con batería cargada y módulo de comunicación activo (Bluetooth o Wi-Fi).

## 3. Guía de Uso Paso a Paso

1. **Abrir la Aplicación:**
   * Inicie la aplicación en el navegador de su teléfono abriendo la dirección local provista por el servidor o cargando `app/index.html`.
2. **Habilitar los Sensores:**
   * Presione el botón **"Activar Sensor Móvil"**. Si su teléfono solicita permisos de movimiento, presione "Permitir".
3. **Seleccionar Modo de Vehículo:**
   * Seleccione **"Modo Auto"** para el vehículo terrestre o **"Modo Dron"** para el vuelo.
4. **Operación Segura (Gatillo Hombre Muerto):**
   * Por seguridad contra accidentes, el vehículo solo responderá cuando mantenga presionado el botón azul **"MANTENER PARA CONDUCIR"**.
   * **Inclinación adelante/atrás:** Acelera o retrocede el vehículo.
   * **Inclinación izquierda/derecha:** Gira la dirección del auto o alabea el dron.
5. **Parada Inmediata:**
   * Suelte el botón para detener el avance inmediatamente.
   * En caso de emergencia, pulse **"PARADA DE EMERGENCIA"**.
